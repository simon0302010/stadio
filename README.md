# stadio

A piece of software that allows you to control your entire computer using a game controller.

# Compatibility

It is confirmed working on macOS and Linux on X11.
Wayland doesn't move the window to the mouse cursor.
Untested on Windows.

# Features

- Full keyboard input using the left stick
- Moving the mouse using the right stick
- Slow/Fast scrolling using triggers
- Some more button stuff
- Written in rust

# Installation

It's easy to install. Literally just `cargo build --release`.
